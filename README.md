# ЧЗ-этикетки — набор программ (одна папка, общий встроенный Python)
Графический интерфейс на базе Python для создания и печати этикеток «Честный знак»
*Создано с помощью ИИ
(применимо для таможенных складов)

В папке три программы, все работают без установки Python: окружение
(win-embed) и библиотеки (win-embed\libs) ОБЩИЕ на все три.

1. Генератор этикеток из CSV
   Двойной клик: Generiator_datamatrix.bat — окно генератора PDF/PRN
   по CSV с кодами маркировки. Консольный режим:
       Generiator_datamatrix_console.bat файл.csv --no-gui
   Рядом должна лежать папка assets (шрифт подписей).

2. Печать на принтер TSC из CSV (Beta версия требует тестирования)
   Двойной клик: Pechat_etikalet_TSC.bat — окно отправки этикеток
   на принтер (по имени принтера Windows, сетевому пути или IP:порт).
   Если окно не открылось — Pechat_etikalet_TSC_console.bat.
   Пример CSV: example.csv (разделитель AI внутри серийника — байт GS).

3. Конвертор PDF-выгрузок ЧЗ на малоформатные этикетки
   Окно: Konvert_PDF_v_etiketki.bat — добавить PDF выгрузки, указать
   размер листа (по умолчанию 20×29) и разрешение принтера; программа
   вырежет каждый код на отдельный лист и проверит, что он читается.
   Консоль/перетаскивание: Konvert_PDF_v_etiketki_konsol.bat —
   перетащите PDF-файлы на него.

Общее
-----
- Всё содержимое архива держите вместе: папки win-embed (Python, Tkinter)
  и win-embed\libs (библиотеки) нужны всем трем программам.
- Если что-то из окон не открывается — запускайте вариант *_console.bat:
  в окне консоли будет видно сообщение об ошибке.
- Общие библиотеки: Pillow 13.0.0, pystrich, reportlab, PyMuPDF 1.28.2,
  zxing-cpp 3.1.1 (все — под Python 3.13 из win-embed).
