# requirements.txt — «ЧЗ-этикетки-портативный»
#
# Назначение файла: точный состав библиотек, входящих в сборку, для установки
# в обычный Python и для пересборки папки win-embed\libs.
#
# ВАЖНО про портативную сборку: устанавливать что-либо НЕ НУЖНО — все
# библиотеки уже лежат в win-embed\libs, а сам Python — в win-embed.
# Файл нужен для двух случаев:
#   1) запуск скриптов системным Python 3.13 (например, для доработки):
#        pip install -r requirements.txt
#   2) пересборка библиотек под Windows (x64, Python 3.13):
#        pip download --no-deps --python-version 313 --platform win_amd64 \
#            --only-binary :all: -r requirements.txt -d wheels
#      затем распаковать wheels\*.whl в win-embed\libs (папки PIL, pymupdf,
#      fitz, zxingcpp), удалить pymupdf\mupdf-devel и PIL\_avif*.pyd.
#
# Версии зафиксированы — они проверены вместе в текущей сборке.
# Pillow обновлять только ПАРНО: .py-файлы PIL и _imaging*.pyd обязаны быть
# одной версии, иначе ошибка «cannot import name _imaging».
